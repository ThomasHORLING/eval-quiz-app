# J3 — Azure CLI et Azure Container Registry

## Objectif

Provisionner les ressources Azure **uniquement avec Azure CLI**, via un script versionné et réutilisable, puis publier les images frontend et backend dans un registre ACR avec des **tags traçables**.

## Ressources créées

| Ressource | Nom | Détail |
|---|---|---|
| Groupe de ressources | `rg-quiz-app` | Région `switzerlandnorth` |
| Azure Container Registry | `acrquizthorling` | SKU **Basic**, compte admin désactivé |
| Dépôt d'images | `quiz-backend` | Tag = hash court du commit Git |
| Dépôt d'images | `quiz-frontend` | Tag = hash court du commit Git |

## Scripts

| Script | Rôle |
|---|---|
| `scripts/deploy.sh` | Enregistre les fournisseurs Azure, crée le groupe de ressources et l'ACR s'ils n'existent pas, construit et pousse les images |
| `scripts/destroy.sh` | Liste les ressources du groupe, demande une confirmation explicite (`oui`), puis supprime le groupe entier |

### Prérequis

- Azure CLI installé et connecté : `az login` (MFA requise, voir plus bas)
- Docker démarré
- Git Bash (Windows) ou un shell bash (Linux/macOS)
- Lancement depuis la racine du dépôt, **après avoir commité** (le tag est le commit courant)

### Utilisation

```bash
ACR_NAME=acrquizthorling ./scripts/deploy.sh

# Paramètres surchargeables
RG=rg-quiz-app LOCATION=switzerlandnorth TAG=v1 ACR_NAME=acrquizthorling ./scripts/deploy.sh

# Nettoyage (irréversible, confirmation demandée)
./scripts/destroy.sh
```

## Choix techniques

| Choix | Justification |
|---|---|
| `set -euo pipefail` | Le script s'arrête à la première erreur ou variable manquante au lieu de continuer dans un état incohérent |
| Paramètres `${VAR:-défaut}` / `${VAR:?}` | Script réutilisable, aucune valeur sensible écrite en dur |
| Test `az acr show` avant `az acr create` | Script **idempotent** : il peut être relancé sans erreur ni doublon |
| SKU Basic | Le moins coûteux, suffisant pour l'exercice |
| Compte admin ACR désactivé, `az acr login` | Authentification par l'identité Entra ID de l'utilisateur, pas de mot de passe de registre partagé |
| Tag = `git rev-parse --short HEAD` | Chaque image correspond à un commit précis ; on évite `latest`, qui ne dit pas quel code tourne |
| `docker build --platform linux/amd64` | Architecture attendue par Azure Container Apps |
| Build local + `docker push` | Les ACR Tasks (`az acr build`) sont souvent indisponibles sur les abonnements étudiants |
| `export MSYS_NO_PATHCONV=1` | Empêche Git Bash (Windows) de transformer les identifiants Azure `/subscriptions/...` en chemins Windows |
| `.gitattributes` : `*.sh text eol=lf` | Évite les fins de ligne CRLF qui font échouer bash (`$'\r': command not found`) |

## Restrictions rencontrées (abonnement Azure for Students)

| Restriction | Impact | Mesure prise |
|---|---|---|
| Régions autorisées limitées par une stratégie Azure | Création refusée hors des régions autorisées | Région `switzerlandnorth` utilisée par défaut dans le script |
| MFA obligatoire pour les opérations d'écriture (erreur `AADSTS50076`) | Le premier lancement a échoué à la création du groupe de ressources, sans rien créer (`set -e`) | Reconnexion avec `az login --tenant <id>` et validation MFA. Pour la CI (J6), une identité de service sera utilisée à la place du compte personnel |
| ACR Tasks potentiellement bloquées | `az acr build` inutilisable | Build et push depuis le poste de travail |

## Vérification

```bash
az resource list -g rg-quiz-app -o table
az acr repository list -n acrquizthorling -o table
az acr repository show-tags -n acrquizthorling --repository quiz-backend -o table
az acr repository show-tags -n acrquizthorling --repository quiz-frontend -o table
git log --oneline -1    # le hash correspond au tag des images
```
